# Checklist — cierre de pasantía
- [x] Control de existencia F1–F5 y nomenclatura exacta.
- [x] Control cronológico de inicio y fin entre F2/F4/F5.
- [x] Regla F2: Respuesta de organización próxima a finalización, unos días antes o después.
- [x] Diferencia de cinco días aceptada en caso de prueba; no inventar máximo genérico.
- [x] Conciliación de horas declaradas, jornadas documentadas y horas verificadas.
- [x] Informe listo para WhatsApp y reenvío al mismo tutor.
- [ ] Confirmar obligatoriedad y documentación específica del ticket de cierre.
- [ ] Definir evidencia de horarios diarios y reglas de acreditación de horas.
- [ ] Definir criterios finales de aprobación de cierre.

- [x] Control de firma del profesor tutor en F2 y F5 (caso de prueba: Roger Armoa).
- [x] La ausencia o imposibilidad de verificar la firma se informa por formulario y requiere revisión.
- [x] Informe final F5 preferentemente de una página; si excede, aviso no bloqueante.
- [x] Exceso de extensión por sí solo no modifica el dictamen final.

- [x] F4 debe incluir evaluación de la empresa y firma verificable de su representante.
- [x] Comparar preferentemente al firmante/evaluador F4 con el contacto o responsable de empresa declarado en F1; diferencia de persona es aviso, no rechazo automático.
- [x] Verificar igualdad de inicio y fin entre F2, F4 y F5, así como inicio anterior o igual a fin.
- [x] La tolerancia de «Respuesta de la Organización» F2 no modifica la coincidencia estricta de fechas inicio/fin.

- [x] Título obligatorio del mensaje: INFORME DE AUDITORÍA DE CIERRE DE PASANTÍA.
- [x] Escala de calificación definida: E = Excelente; MB = Muy Bueno; B = Bueno; A = Aceptable.
- [x] Separar calificación académica y estado administrativo de la auditoría.
- [x] Revisar declaración de empleo en el escrito del informe final F5.
- [x] Si declara ser empleado de la empresa receptora, exigir certificado de trabajo y registrar su existencia.
- [x] Si la situación laboral no está indicada, solicitar aclaración sin presumir empleo.

- [x] Comprobar consistencia de cédula de identidad entre F1, F2, F3, F4 y F5.
- [x] Comprobar consistencia de nombres y apellidos completos entre F1, F2, F3, F4 y F5.
- [x] Comparar cédulas sin puntos/espacios, pero exigir los mismos dígitos; admitir solo diferencias ortográficas superficiales en nombres.
- [x] Reportar discrepancias por formulario sin publicar innecesariamente la cédula completa en WhatsApp.
